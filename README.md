# Motion Intent Protocol (MIP)

Human–agent creative alignment for motion and animation.

MIP converts human descriptions or existing design references into glossary-grounded, human-approved, versioned specifications and inspectable prototypes before production implementation.

**Workflow:** Intent → Semantic Alignment → Prototype Review → Implementation → Verification.

**Status:** Draft RFC v0.7; implementation not yet complete.

## Principles

- Resolve unknown and ambiguous design language before approval.
- Each phase produces locked, versioned artifacts consumed by the next phase.
- Prototype review supports storyboard, transitions, animation and timeline scrubbing.
- Human approvals refer to exact reviewed artifact digests.
- Changes invalidate affected downstream approvals.
- Reference-first imports distinguish observed facts from inferred creative intent.
