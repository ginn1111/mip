# Spec — AGE-35 Video/GIF and storyboard evidence extractor

Source: Linear AGE-35; RFC 0007 (never claim exact easing or original code from video; keep uncertainty; human approves before locking).

## Problem

A reference video, GIF or storyboard cannot become a Reference Evidence Pack (AGE-34).

## Desired behavior

- **B1 Input.** A local video or GIF, or a storyboard folder of images with a captions JSON. Sources fingerprinted with SHA-256 of file bytes.
- **B2 Sampling.** `ffmpeg`/`ffprobe` (external, detected at runtime) extract frames at a fixed rate (default 10 fps); key moments where mean frame difference exceeds a threshold. Missing tools fail with one clear line.
- **B3 Observations.** Each records `timeRangeMs`, `measurementMethod` (`frame-diff`, `centroid-track`, `storyboard-caption`), `measuredValue`, `confidence`. Motion is approximate (centroid of changed pixels). No easing curve is asserted.
- **B4 Annotations.** A human annotation file can add `DECLARED` bindings and actor names.
- **B5 Output.** A pack valid under the AGE-34 schema and `validateEvidencePack`, plus an uncertainty report.

## Inputs / outputs

In: file or folder, optional annotations. Out: evidence pack JSON, uncertainty report.

## Constraints

- Approvals: every approval, creative or not, happens in the web reviewer by a human (project owner decision 2026-10-15). Code never creates an approval or a lock.
- Duplicate JSON keys are never allowed; parse stored or received JSON with `parseStrictJson` (`packages/artifacts/index.mjs`).
- Protocol identifier is `mip/0.7`.
- No new runtime dependency unless this spec says so.

## Acceptance criteria
- [ ] On a synthetic video generated by ffmpeg in the test (a square moving left to right), the extractor reports motion along x with confidence below 1 and no easing claim (B2, B3).
- [ ] Output validates under AGE-34 (B5).
- [ ] Missing `ffmpeg` gives a one-line error (B2).
- [ ] The Scorpio Canvas preview recorded to video produces an uncertainty report.
- [ ] `npm test` passes.

## Edge cases
- Clips shorter than one sample interval give one low-confidence observation.
- Duplicate frames give no motion.

## Assumptions and open decisions (human decides)
- No real Scorpio reference video exists; the human must supply one for the final check. Owner: user.
